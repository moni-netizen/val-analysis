# val-analysis
A Report written in 2025 analysing Valorant VCT 2024 Tournament Performance. This was done in MXB262, semester 1 but will be receiving some refactors the next coming months! Data was retrieved from Ryan Luong on [Kaggle](https://www.kaggle.com/datasets/ryanluong1/valorant-champion-tour-2021-2023-data). Thank you!

## Tech stack + Libraries
The primary language was R and the libraries include: ggplot2, dplyr, knitr, tidyverse, ggnetwork, igraph, ggraph, rnaturalearth, sf, ggrepel, ggiraph, ggiraphExtra, cowplot, patchwork
